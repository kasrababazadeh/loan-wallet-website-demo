# Loan Wallet Website Demo

A full-stack web application for managing loans and wallet transactions. This project features a modern React frontend with real-time capabilities and a robust Django backend powered by Django REST Framework and WebSockets.

## 🌟 Features

- **User Authentication & Management**: Custom user model for secure account management.
- **Wallet & Loan Management**: Track loans, wallet balances, and financial transactions.
- **Real-Time Updates**: Live notifications and data syncing using Django Channels, Socket.io, and Pusher.
- **RESTful API**: Fully documented API endpoints using Swagger/OpenAPI (`drf-yasg`).
- **Modern UI**: Responsive and sleek user interface built with Tailwind CSS, including RTL (Right-to-Left) support.
- **Interactive UX**: Toast notifications, smooth client-side routing, and infinite scrolling capabilities.

## 🛠️ Tech Stack

### Frontend
- **React 18** (Bootstrapped with Create React App)
- **Tailwind CSS** (with `tailwindcss-rtl` for RTL support)
- **React Router DOM** for client-side routing
- **Axios** for HTTP requests
- **Socket.io-client** & **Pusher-js** for real-time WebSocket communication
- **React Toastify** for UI notifications
- **React Icons** & **React Intersection Observer**

### Backend
- **Django 5.0.6** & **Django REST Framework**
- **Django Channels** & **Daphne** for ASGI/WebSocket support
- **PostgreSQL** as the primary relational database
- **drf-yasg** for automated Swagger API documentation
- **django-cors-headers** for handling Cross-Origin Resource Sharing

## 🚀 Getting Started

Follow these instructions to set up the project locally for development and testing.

### Prerequisites

Make sure you have the following installed on your machine:
- **Node.js** and **npm**
- **Python 3.8+**
- **PostgreSQL**

### 1. Clone the Repository

```bash
git clone https://github.com/kasrababazadeh/loan-wallet-website-demo.git
cd loan-wallet-website-demo
```

### 2. Backend Setup (Django)

Navigate to the backend directory:
```bash
cd backend
```

Create and activate a virtual environment:
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

Install the required Python packages:
```bash
pip install django djangorestframework channels daphne django-cors-headers drf-yasg psycopg2-binary
```
*(Note: If a `requirements.txt` is added in the future, simply run `pip install -r requirements.txt`)*

**Configure the Database:**
Open `backend/backend/settings.py` and update the `DATABASES` configuration with your local PostgreSQL credentials:
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'loan_wallet_project',
        'USER': 'your_postgres_user',
        'PASSWORD': 'your_postgres_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```

Apply database migrations and create a superuser:
```bash
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
```

Start the backend server (using Daphne for ASGI/WebSocket support):
```bash
daphne backend.asgi:application
```
*Alternatively, for standard HTTP requests without WebSocket testing, you can use `python manage.py runserver`.*
The backend will typically run on `http://localhost:8000`.

### 3. Frontend Setup (React)

Open a new terminal window and navigate to the frontend directory:
```bash
cd frontend
```

Install the npm dependencies:
```bash
npm install
```

Start the development server:
```bash
npm start
```
The frontend will open in your browser at `http://localhost:3000`.

## 📖 API Documentation

Once the backend is running, you can explore the fully interactive API documentation generated by `drf-yasg`:
- **Swagger UI**: `http://localhost:8000/swagger/`
- **ReDoc**: `http://localhost:8000/redoc/`
